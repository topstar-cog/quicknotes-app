\# QuickNotes



QuickNotes is a simple web application for creating, organising, searching, and deleting notes. Each note has a category and creation date. Submitted notes are saved in the browser using localStorage and remain available after refreshing the page.



\## Features



\- Add notes under Personal, Work, or Study.

\- Validate input and limit notes to 200 characters.

\- Display note text, category, and creation date.

\- Delete individual notes.

\- Search notes without case sensitivity.

\- Save submitted notes using localStorage.

\- Display an accurate note count.

\- Show a message when no search results match.

\- Responsive layout for smaller screens.



\## How to Run Locally



1\. Download or clone this repository.

2\. Open the project folder.

3\. Open `index.html` in a web browser.

4\. Enter a note, select a category, and click Add Note.

5\. Search for notes using the search field.



No server or package installation is required.
